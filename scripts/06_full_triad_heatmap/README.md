# Full Triad RNA-seq Analysis: Top 20 DEG Heatmap

Generation of a heatmap showing the top 20 differentially expressed genes (DEGs) identified from the OAC vs Normal Oesophagus DESeq2 comparison across the matched triad cohort of Normal Oesophagus, Barrett's Oesophagus and Oesophageal Adenocarcinoma (OAC).

The heatmap visualises expression patterns for the most statistically significant DEGs across all matched samples, allowing assessment of expression changes across disease progression within individual patients.

## What the script does
1. Loads the previously generated DESeq2 object (dds_full_triad.rds)
2. Loads differential expression results from the OAC vs Normal Oesophagus comparison
3. Loads the triad cohort metadata
4. Verifies that all samples in the DESeq2 object are represented in the metadata
5. Performs variance stabilising transformation (VST) on the count data using DESeq2
6. Selects the top 20 genes ranked by adjusted p-value (padj) from the OAC vs Normal Oesophagus comparison
7. Filters the selected genes to those present in the transformed expression matrix
8. Replaces Ensembl gene IDs with HGNC gene symbols where available
9. Extracts expression values for the selected genes across all samples
10. Creates sample annotations showing patient identifier and tissue type
11. Orders samples by patient and tissue type to preserve the matched triad structure
12. Inserts visual gaps between patients to improve interpretation
13. Scales expression values by gene (row-wise z-score scaling)
14. Generates a heatmap using pheatmap
15. Colours samples by tissue type using predefined annotation colours
16. Saves the heatmap as a PNG image
17. Saves R and package version information to support reproducibility

## Requirements

R packages:

DESeq2, dplyr, pheatmap

The required packages should be installed before running the script.

Input files

The script requires output files generated by the Full Triad DESeq2 differential expression analysis.

DESeq2 object

dds_full_triad.rds

Contains the fitted DESeq2 dataset used for variance stabilising transformation and expression extraction.

Differential expression results

DESeq2_OAC_vs_Normal.csv

The gene-level differential expression results generated from the OAC vs Normal Oesophagus comparison.

The file should contain at minimum:

EnsemblID
Gene
log2FoldChange
padj

The top 20 genes with the lowest adjusted p-values are used for heatmap generation.

## Metadata

full_triad_metadata.csv

The metadata file should contain:

MatrixID
SampleID
TissueType

The script uses:

MatrixID to match metadata to expression data
SampleID to group matched samples from the same patient
TissueType to order and annotate samples

## Outputs

All outputs are written to:

Full_Triad_Analysis/

The script produces:

Heatmap_Top20_DEGs_Full_Triad.png — heatmap of the top 20 DEGs across all matched triad samples
session_info_heatmap.txt — R version and package information used for the heatmap analysis
